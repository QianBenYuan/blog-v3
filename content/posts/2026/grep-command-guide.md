## grep 命令用法

---

### 一、grep 是什么?什么时候用它?

一句话:**grep 负责在一堆文本里"按条件找行",把符合条件的行打印出来。**

- Linux / Mac 自带,Windows 的 **Git Bash**、WSL 里也能用(你在 VM 里用的就是它);
- 它的处理单位是"**行**":不是找"词"给你标出来,而是把**整行**挑出来;
- 它不仅能搜文件,还能**过滤别的命令的输出**(配合管道 `|`,这个超常用)。

**什么时候想到用它?**

| 需求 | 用 grep |
|---|---|
| 一个大字典/日志/源码里,想找含 `flag` 的行 | ✅ |
| 想数一数某个词出现多少行 | ✅ |
| 想把"符合规则之外的异类"挑出来(找异类) | ✅ |
| 想从 curl 抓回来的网页里抓某段 | ✅ |
| 想在一个文件夹所有文件里搜 | ✅ |

---

### 二、最基础的写法

```bash
grep 关键词 文件路径
```

比如有个文件 `demo.txt`,内容是:

```text
hello world
hello ctf
goodbye flag
flag{secret}
```

搜含 `hello` 的行:

```bash
grep hello demo.txt
```

输出:

```text
hello world
hello ctf
```

**注意**:grep 默认是"**模糊包含**",搜 `flag` 会把 `flag{secret}`  整行打出来(只要这一行里**任何位置**出现了关键词就算命中)。

---

### 三、最常用的几个参数

| 参数 | 作用 | 例子 |
|---|---|---|
| `-i` | **忽略大小写**(搜 flag 也能命中 FlAg) | `grep -i flag demo.txt` |
| `-n` | 顺便显示**行号** | `grep -n hello demo.txt` → `1:hello world` |
| `-c` | 只**数有几行**命中,不打印内容 | `grep -c flag demo.txt` → `2` |
| `-v` | **反向选择**:打印"不包含"关键词的行 | `grep -v "/" guji_catalog.txt` |
| `-E` | 使用**扩展正则**(想用 `|`、`+`、`?` 等必加) | `grep -E "flag|secret" demo.txt` |
| `-r` | **递归**搜整个文件夹 | `grep -r "flag{" .` |
| `-o` | 只输出**命中的那一段**,不输出整行 | `grep -oE "flag\{[^}]+\}" x.txt` |
| `-l` | 只列**文件名**(哪个文件里有) | `grep -rl flag .` |
| `-w` | **整词匹配**(flag 不匹配 flags) | `grep -w flag demo.txt` |
| `-A 2` | 命中行**后面**再带 2 行 | `grep -A 2 error log.txt` |
| `-B 2` | 命中行**前面**再带 2 行 | `grep -B 2 error log.txt` |
| `-C 2` | 命中行**上下**各带 2 行 | `grep -C 2 error log.txt` |

#### 组合起来看(带行号 + 忽略大小写 + 数数)

```bash
grep -in "flag" demo.txt     # 忽略大小写并带行号
grep -c "flag" demo.txt      # 有几行含 flag
grep -vc "flag" demo.txt     # 有几行不含 flag(数"异类"很好用)
```

> `-v` 和 `-c` 连起来 = "数不命中的行",这就是我们找 `true_file` 的反向思路。

### 四、配合管道 `|`:过滤别的命令的输出(常用)

管道的意思:**把前一个命令的输出,塞给后面的命令当输入**。

```bash
命令1 | grep 关键词
```

实战例子:

```bash
ls -la | grep guji                 # 只列出文件名里带 guji 的
curl -s http://... | grep "flag" # 网页返回里抓 flag
history | grep rm                   # 找自己之前敲过带 rm 的命令
cat guji_catalog.txt | grep flag   # 等价于 grep flag guji_catalog.txt
```

### 五、正则入门

grep 搜"字符"还不够,还得会搜"**一类**字符"。搜"一类"用的语法叫**正则表达式**。

#### 5.1 普通 vs 扩展:记一个要点

- 默认是"基础正则",很多符号(如 `+`、`|`、`?`)会被当成普通字符;
- 加 **`-E`** 就是"扩展正则",这些符号才有特殊含义。

**建议:想用正则时,一律加 `-E`。**

#### 5.2 常用元字符(记这几个就够起步)

| 写法 | 含义 | 例子 |
|---|---|---|
| `.` | 任意**一个**字符 | `a.c` 能匹配 `abc`、`a1c` |
| `*` | 前面那个字符出现 **0 次或多次** | `ab*c` 匹配 `ac`、`abc`、`abbc` |
| `+` | 前面那个字符出现 **1 次或多次**(要 `-E`) | `ab+c` 匹配 `abc` 不匹配 `ac` |
| `?` | 前面那个字符出现 **0 或 1 次**(要 `-E`) | `colou?r` 匹配 color/colour |
| `^` | **行开头** | `^flag` 匹配以 flag 开头的行 |
| `$` | **行结尾** | `flag$` 匹配以 flag 结尾的行 |
| `[]` | **字符集合**,任意一个 | `[0-9]` 数字,`[a-z]` 小写 |
| `[^]` | 集合取反:不要这些 | `[^0-9]` 非数字 |
| `\|`(基础正则) / `|`(加 `-E`) | **或** | `flag\|secret`(不加 -E)或 `flag|secret`(加 -E) |
| `()` | **分组**(要 `-E`) | `(cat|dog)` |
| `{}` | 出现次数(要 `-E`) | `[0-9]{3}` 正好 3 位数字 |

#### 5.3 一个能直接复用的例子:从文本里抓 flag{...} 格式的 flag

```bash
grep -oE "flag\{[^}]+\}" 任意文件
```

拆开看:

- `-o`:只输出命中的那段;
- `flag\{`:匹配 `flag{`(花括号 `{` 是特殊字符,所以前面加 `\` 转义);
- `[^}]+`:一个或多个"不是 `}`"的字符(= flag 内容);
- `\}`:以 `}` 收尾。

> 这就叫"**提取**"而不是"筛行",打 CTF 读网页/读文件抓 flag 时极常用。

### 六、回到实战:这几题我们是怎么用 grep 的

#### 例 1:大字典里找"格式不对的异类"(古籍翻阅)

```bash
grep -v "/" guji_catalog.txt
```

含义:正常条目都含 `/`,把**不含 `/`** 的行全打出来 → 只剩 `true_file`。

#### 例 2:数诱饵(看看有多少条带 flag 的假书)

```bash
grep -c "flag" guji_catalog.txt
# 输出一个数字,说明都是幌子,别死磕
```

#### 例 3:忽略大小写找敏感词

```bash
grep -inE "flag|secret|admin|password" 某文件
```

#### 例 4:网页返回里直接抓 flag(配合管道)

```bash
curl -s "http://目标/read?book=../../flag" | grep -oE "flag\{[^}]+\}"
```

#### 例 5:递归搜一个项目目录,看 flag 藏在哪个文件

```bash
grep -rl "flag{" ./某个目录
```

### 七、一页速查

| 我想…… | 命令 |
|---|---|
| 在文件里==搜词== | `grep 词 文件` |
| 忽略==大小写==搜 | `grep -i 词 文件` |
| 带==行号==搜 | `grep -n 词 文件` |
| 数有==几行命中== | `grep -c 词 文件` |
| 打印==**不**含词==的行 | `grep -v 词 文件` |
| 数不含词的行(==找异类==) | `grep -vc 词 文件` |
| 搜==多个词==(或) | `grep -E "词1|词2" 文件` |
| ==递归==搜整个目录 | `grep -r 词 目录` |
| 只输出命中的那段 | `grep -oE "正则" 文件` |
| 只看哪个文件有 | `grep -l 词 目录/*` |
| 命中行上下带 3 行 | `grep -C 3 词 文件` |
| ==过滤命令==输出 | `命令 \| grep 词` |
| 从文本抓 flag{...} | `grep -oE "flag\{[^}]+\}"` |

### 八、注意事项

1. **关键词里有空格/特殊符号一定要加引号**:
   `grep "hello world" f.txt` ✅;`grep hello world f.txt` ❌(会被当成两个词加一个文件)
2. **`.`、`*`、`[`、`]`、`^`、`$`、`(`、`)`、`{`、`}`、`|`、`\` 等在正则里有特殊含义**(注意 `/` 不是特殊字符,直接搜就行),想当普通字符匹配要加 `\` 转义,或用 `-F`(纯文本模式)。
3. **Windows 中文乱码问题**:文件若是 GBK 编码,grep 中文可能乱。把文件转成 UTF-8 再搜最省心(记事本另存为选 UTF-8)。
4. **grep 以"行"为单位**:只打印整行,除非你用了 `-o`。
5. **搜整个目录记得 `-r`**,否则只搜当前文件/会报错。
6. **`-v` 是"不包含"**,不是"倒序";`-n` 是行号,不是"不"——这两个别记混了。
7. 正则里的 `|`(或)恰好和 shell 的管道符是同一个字符,所以**必须放在引号里**:`grep -E "flag|secret" f.txt`。只有不加 `-E` 的基础正则才把"或"写成 `\|`。

---

### 九、总结

> **grep = 在一堆"行"里,按"包含/不包含/正则"挑出我要的行;再配上 `-c/-v/-o/-E` 和管道 `|`,就是做题时最顺手的"找线索"工具。**

口诀版:

```text
找词用 grep,忽略大小写加 -i,
要行号加 -n,要计数加 -c,
要排除加 -v,要递归加 -r,
要正则加 -E,只取命中加 -o。
```
